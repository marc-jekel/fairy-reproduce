# fairy: reproduce the figures and tables

Scripts that reproduce the figures and tables of the paper and of the online supplement with the R package fairy.

Open in the browser: [![Binder](https://mybinder.org/badge_logo.svg)](https://mybinder.org/v2/gh/marc-jekel/fairy-reproduce/HEAD?urlpath=rstudio)

Then, in the RStudio terminal: `Rscript run_all.R`

Overview of all figures and tables: https://modeling-for-everyone.eu/posts/fairy/#reproduce
